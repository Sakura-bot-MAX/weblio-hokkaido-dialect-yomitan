## 安装方法（Yomitan / Yomichan）

1. 打开 Yomitan 设置 → 辞書 → 导入（Import）
2. 选择本目录下任意一个 `[JA-JA Dialect] Weblio….zip`（可多选/全选）
3. 等待索引完成即可查询

每个 zip 内含 `index.json`、`term_bank_1.json`、`icon.png`，已配置 `isUpdatable` 自更新字段（发布到 GitHub Release 后生效）。
